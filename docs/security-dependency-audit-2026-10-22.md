## Limits

This covers those four repository npm lockfiles only. It is not a full software bill of materials for the workstation, Electron applications, Docker images, Python virtual environments, Cargo dependencies, other source checkouts, or virtual machines. A clean result for a lockfile is not a clean bill of health for its runtime. The machine audit records outdated Node runtimes independently.
